## 操作流程

1. 创建任务先选择本地PDF。本地入口可“选择文件”多选PDF，或“选择文件夹”递归筛选用户电脑文件夹及子文件夹中的PDF（扩展名不区分大小写）；其它文件不上传。当前文件清单按完整PDF字节SHA去重后计数，异名同内容保留一份并提示，同名异内容保持独立；服务端再次核对并复用已有论文/文件，已有重复历史记录不迁并或删除。每批最多20份不同内容、50MiB/篇；超过上限时整次不加入并保留原清单，按提示分批。选择后自动逐文件串行上传，独立显示成败，可重试失败项或移除未提交项；上传不调用模型。文件与文件夹入口共用癌种→图像模态两层范围和模型设置，默认不限且均可多选；由手工JSON配置可选关联，空选/失效明确提示并阻止开始，不自动放宽。浏览器不支持目录选择时仍可使用多选文件。上传后的PDF保存在服务器；可从侧栏底部“存储管理”查看占用并手动预览清理，最近24小时的上传资料、任务及其它仍有引用的文件受保护。
2. 点击开始后，每篇保留独立子run、2个FIFO槽与原每run预算，用户层按提交任务展示。首次开始按有效未移除成员数固定单篇或批量，标题、范围、模型与batch_id一起冻结；部分创建失败保留草稿与幂等key可继续重试，仅全部有效成员受理成功后清空一次性表单、显示成功提示并打开统一结果，保留范围和模型偏好。单篇留空标题使用原文件名；批量留空使用批量默认名。标题不改论文来源。同论文不同提交始终分开，缺少提交metadata的旧记录不猜组；侧栏/历史数量按提交任务统计。整页重载不恢复未提交草稿，后台已受理任务继续运行。
3. 在“抽取结果”阅读连续原文和明确配图，使用“排除此条”或“恢复保留”取舍。每条描述下显示对应配图状态；明确配对时直接展示整幅Figure和完整原图注，不明确时保留文字，不用独立图片猜配。单篇任务进度显示排队、解析、原文处理和汇总核验；批量进度显示各阶段篇数及“已结束论文/实际已提交论文”比例，结束包含失败、取消和中断，100%结束不代表全批处理完成。只有每篇自身版本化流程结果完成（或旧任务充分证据的只读投影）且结果落盘时，整批才显示完成；单篇内容块/历史行数或SSE不代替整批进度。系统自动完成汇总核验、交付检查与保存，无需逐条确认保留。疑似字形按解析原串交给agent判断，检测留后台；真实来源缺失、结构冲突及处理失败仍如实披露。同源成员、来源版本与高级操作集中在“说明”，原片段/指纹和主目标/背景语义保持。
4. 结果默认保留；排除可恢复，旧有效拒绝延续，修改内容不会悄悄恢复。可选来源/标签修订从“说明”进入并记录修订人；日常取舍无需审核人或理由。开发抽样、医学核验与旧评价独立，默认保留不表示医学批准，保留背景仍是背景。
5. 单篇可下载当前未排除结果的JSONL、CSV或证据包；批量下载一个统一证据包，内含逐成员原包和完整成员manifest，保留run/paper/原页/图像隔离。0保留成员明确列出，不把空成员藏起；任一有内容成员来源阻塞会标明成员并使整包失败。默认保留不表示医学批准；来源缺失或SHA不符的既有导出校验保持。

在左侧“抽取任务”或“任务与历史”选择提交任务直接查看结果；批量无需先选子任务。每个任务只有一个“⋯”菜单，取消批量任务作用于该批全部活动成员，已保存结果保留；删除确认会列出整批已提交论文。删除前预检目标全成员自身活动、收尾及保存；已结束目标同事务删除结果/版本/取舍/审阅/事件/导出并持久记录删除标记。同论文其它独立任务仍在准备、运行或写入时，只延后物理文件清理，逻辑删除成功并返回200；相关守卫释放、已有清理成功释放及重启会恢复既有待清理计划。原PDF与其它提交仍在引用的来源保留；真实文件清理失败仍返回503并可重试，不恢复任务。旧页面按单run删除批量成员会返回409，须刷新从整批菜单操作。技术事件与当前来源信息在“说明”中。

后续新增或修改用户可见的“展开/详情/更多”入口，须保持主页面及相邻区块的尺寸和位置稳定。主页面使用浮层、抽屉或对话框承载额外内容，设置固定或最大高度与内部滚动；条目、文件名或正文数量增加时不得推挤原布局。手机窄屏同样适用，并须支持键盘访问、Esc、点击外部关闭与焦点返回原入口。页码定位等离开详情的动作须先关闭浮层再显示目标原文。已处在固定高度、内部可滚动说明/编辑抽屉中的技术细节可在容器内展开，不要求机械替换。

本轮已应用于已提交论文、主结果原文上下文、来源告警版本、PDF页脚版本与关于工作台；既有范围/模型/额度弹窗及任务选择/导出浮层保持。此为持续界面约束，同样适用于存储管理。

## 模型与限额

默认模型已选AGICTO **gpt-6-luna / medium / openai-responses**，这是成本方向与工程兼容性选择。默认模型已选定，普通服务已启用，用户手动开始后按每run独立限额执行；已有结果仍可查看、审核与导出。 普通服务接纳gpt-6-luna→data-zone-standard-gpt-6-luna精确返回对，依据用户/委托部署选择；旧igpt厂商确认独立留证，不将新对或底层权重写成已认证，其它未知返回名仍停止。

用户选择继续保留Luna medium。本轮核验的是既有固定配置：medium、8192输出上限、新建内存session、固定中立cwd、无环境规则自动加载及关闭SDK自动重试；未新增模型参数或修改额度。默认Luna medium不加入未经兼容证实的temperature、top_p或seed；本地SDK跨模拟日期的相同输入请求体一致，只证明工程传输稳定，不保证完整多轮抽取完全同答。真实任务与来源标识保持独立，不用旧回答充作新任务；本轮未做付费医学输出复验，参数来源及限制见本轮报告`item4.model_parameters`。

在“创建任务”的“模型配置”中选择AGICTO模型，或点击“添加模型”填写模型ID并保存选择；高级设置折叠提供Responses/Chat Completions、medium/不发送推理参数、本地上下文与输出上限。新增默认上下文32768、输出4096 token，使用Chat Completions且不发送推理参数；这些是本地守卫配置，不证明供应商容量或模型可用性，本轮未进行真实模型调用验证。配置以不可变档案保存，修改时另存新档案；新增模型只接受其model_id的精确返回，不继承Luna别名。选择只影响新任务；准入、排队、重试和同一批次首启均使用冻结的范围、submission及模型快照。

普通用户仅点击开始；上传、查看、审核和导出不发模型请求，不填写实验授权表。每个新run独立最多**80请求、200万输入token、12万输出token、30分钟执行时间**；已实现2个FIFO执行槽，第三任务持久排队且可取消；重启标中断，不自动续跑。 排队等待单列，执行时间包含CPU解析、模型和全文汇总。有限重试计入本次预算，无自动循环或旧试验余额继承。请求/时间受应用硬限，token按本地预留及供应商回报计量；不承诺供应商货币账单绝对截断。

服务器管理provider、密钥、端点、目录及硬限额，前端仅在现有AGICTO内新增/选择模型配置；添加配置不发模型请求。克隆示例保持模型关闭；当前实例的实际模型/额度/启用状态以页面及服务capabilities为准。医学目录的配置能力与目录内容是否经真实医学核验分开。

## 手工维护抽取范围

唯一运行源为[`config/scope-catalog.json`](config/scope-catalog.json)：`cancers`保存稳定ID、显示名、`image_type_ids`，`image_types`保存模态ID和显示名；均可选填`aliases`与简短`description`。直接增删改JSON、保存后刷新工作台即更新选项和联动，无需改代码、重建或重启。ID不可复用；删除模态须同时移除癌种引用。检查命令：

```bash
bash scripts/with-node.sh npm run check:scope-catalog
```

版本由文件字节SHA自动生成。刷新会保留未提交草稿原选择ID并接纳新版本；失效项保留在界面直到用户取消/改选。未刷新就提交旧版本返回409，提示刷新，服务不会替换范围自动重试。JSON不可用或有误仅禁用新任务；已有任务与结果仍可查看。

提交时保存目录快照；排队、执行、来源修订与历史显示均沿用原快照。同批首次成功接纳后，剩余成员与重试继续用服务器已保存的范围、目录和模型；新单篇/新批次用最新文件。新任务不提供特征筛选，原文特征描述开放抽取；旧接口显式请求特征限制会拒绝，历史记录及导出的原scope/特征仍保留。`operator_configured`仅表示运营可处理/可选择范围，结构检查和使用配置都不代表医学审核批准。原35条核验材料已一次归档为[`previous-catalog-material.json`](docs/acceptance/two-layer-catalog-2026-11-14/previous-catalog-material.json)，不再作为并列维护源；原医学待核结论保留。
